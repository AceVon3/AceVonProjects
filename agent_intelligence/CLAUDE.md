## What this app is

A public web app that turns SERFF insurance rate-filing data into signals for insurance agents. Six features: Agency Profile (`/setup`), Overview (`/`, the landing page), Prospect (`/prospect`), Defend (`/defend`), My Carriers (`/my-carriers`, independents only), and Compliance (`/compliance`). Plus a static Methodology page.

## Tech stack (do not substitute without asking)

- Next.js 14 (App Router) + TypeScript + Tailwind CSS
- SQLite via `better-sqlite3`, queried with **raw SQL — no ORM**
- The DB is generated by a Python import script and committed to the repo
- Profile stored in `localStorage` — **no auth, no backend user accounts, no email/password**
- Hosting target: Vercel
- Compliance summaries are **pre-generated and cached** (a generation script writes them to a data file the app reads) — **never fetched live at view time**

## Key domain rules (so you don't have to re-derive them)

- **8 covered states** (have filing data): AZ, CO, ID, MT, NV, OR, UT, WA. All 50 are shown in setup; only these 8 are selectable (`data_coverage: true`). Expanding coverage = flip a flag, no other code changes.
- **8 brands**, derived from `company_name` by prefix rules in the spec. The import must fail loudly on any unmatched company name (don't silently drop or mis-bucket).
- **Multi-entity rollup** = premium-weighted average of `overall_rate_impact`, weighted by `written_premium_for_program`. Keep `entity_count`, `min_entity_impact`, `max_entity_impact` for the tooltip.
- **Thresholds:** Prospect ≥ +5%, Defend ≤ −2%, 12-month lookback. Defined once in constants, never hardcoded in queries.
- **Captive vs independent** visibility is the core logic — read the "Carrier visibility model" section carefully.
- Policyholders column is abbreviated (`13.3k`, `1.4M`, `—` for null). SERFF number lives in the row hover tooltip, not a column.

## Gotchas

- **Tailwind cache after bulk className edits.** After bulk className
  edits (sed, grep replace, find-and-replace across files), always
  `rm -rf .next` before restarting dev. The Tailwind watcher doesn't
  reliably pick up bulk edits — symptoms are CSS files that contain
  only a subset of the `bg-*` / `text-*` classes used in source,
  causing elements to render with transparent backgrounds or default
  text colors. This has bitten twice in this project; clean restart
  is the only reliable fix.
